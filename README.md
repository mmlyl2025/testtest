# Northlight Studio Photography Landing Page

This is a Vercel-ready static landing page for a photography business.

## Customize

- Update the business name in `index.html`.
- Replace `hello@example.com` with your real email.
- Swap the Unsplash image URLs for your own portfolio images.
- Adjust packages and prices in the Sessions section.

## Deploy on Vercel

Import this repo into Vercel. Vercel will serve the static `index.html` automatically.
